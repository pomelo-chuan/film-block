# FILM BLOCK

浏览器里的胶片边框工作室。React 19 + TypeScript + Vite，界面使用 shadcn/ui + Radix UI + Tailwind CSS 4，使用 Canvas 渲染及 JSZip 打包，无后端，照片仅在本地处理。

支持多图上传、固定规格 135 / 120 边框、6 种片基预设和自定义颜色、文字、字色、可调字号及 6 种开源像素 / 点阵字体，可选纯色 / 细颗粒片基。135 齿孔尺寸、间距、圆角与排列自动生成，120 固定无齿孔；没有自定义孔形、孔数、边框宽度或内框线设置。默认统一调整全部照片，也可切换「仅选中」应用到勾选的照片。单张或多张导出 JPEG / PNG，可通过系统分享保存相册，ZIP 作为备用下载。保持原图比例，不裁切；最终图片（含边框）的长边按导出质量限制。

几何规格参考 SpektraLab，详见 [固定胶片规格说明](docs/film-geometry.md)。

## 开发

Node.js 22 或更新版本。

```sh
npm ci
npm run dev
npm test
npm run build
```

## GitHub Pages

Vite base 已配置为 `/film-block/`。在仓库 Settings → Pages → Build and deployment 选择 **GitHub Actions**，推送到 main 后 `.github/workflows/pages.yml` 会测试、构建并发布。

预期地址：https://pomelo-chuan.github.io/film-block/ （成功部署后才可访问）。如果更换仓库名，更新 vite.config.ts 的 base。

界面提供程序生成的示例风景，不依赖远程图片。支持浏览器可解码的 JPG、PNG、WebP 等图片；HEIC 等格式是否可用取决于浏览器。单张图片限制为 1 亿像素，批量导出依次渲染以降低峰值内存。刷新页面会清空上传内容。

片基颜色的调研依据、色值限制与开源字体授权说明见 [docs/film-bases.md](docs/film-bases.md)。字体随网站本地打包，预览与导出均等待字体加载。

片基文字可整体关闭（包括格号）；文字内容、开关、字体、字号和字色保存在当前浏览器 localStorage，刷新后自动恢复，新上传的照片沿用这份文字配方。各张照片的临时调整与照片本身不会缓存。浏览器禁止本地存储时仍可编辑和导出。字体采用 SIL OFL 1.1 授权并本地打包。


## 字体与主题

新增缝合像素 10px、缝合像素 12px 与俐方体 Cubic 11，均包含中文和英文字形；默认缝合像素 12px。保留 Doto、Silkscreen、Press Start 2P，缺少的中文字形通过缝合像素 12px 补全。Pixelify Sans 已移除，旧文字缓存自动迁移到新默认字体。字体授权、版本和覆盖范围见 [docs/fonts.md](docs/fonts.md)。

顶栏支持浅色 / 深色切换，首次打开跟随系统主题；手动选择保存在本机。界面主题不会改变片基、文字、齿孔或导出图片的颜色。


## 导出质量

默认「均衡画质」使用 JPEG 88%，含边框长边最多 3200px，避免照片以大体积 PNG 导出。另有「轻量分享」（JPEG 78%，1920px）、「高画质」（JPEG 95%，6000px）和「无损保存」（PNG，6000px）。小图不会放大。JPEG 档位均为有损压缩，最终文件大小取决于照片内容；准备完成后显示实际图片总体积。批量 ZIP 内的照片遵循同一档位，导出质量选择保存在当前浏览器。


## UI 与移动端

使用 shadcn CLI 4.23.0（2026-11-04 查询的最新版）、官方 Radix 组件、Tailwind CSS 4.3.4。组件源码在 `src/components/ui/`，配置为 `components.json`，路径别名为 `@/`。品牌的浅色 / 深色主题使用统一的 shadcn CSS tokens，并保留已有主题缓存。

交互参考移动端相册编辑器：中央大预览、顶部文字 / 日期快捷开关与主题切换，底部仅保留添加入口和横向照片条。右上角设置按钮打开统一设置面板，包含胶卷（135 / 120）、片基、文字、日期和调整范围，并记住上次打开的分类；照片条旁进入照片选择管理，右上导出按钮进入原有质量选择与导出，准备完成后可保存到相册、分享或逐张下载。删除仍直接位于预览区。保持原有所有编辑、EXIF 日期、缓存、主题和导出功能，单张模式不加入额外胶片画幅；多张拼图见下文。日期可选择经典数码管、Doto、Silkscreen、缝合像素字体及五种格式，字体和格式自动缓存。ZIP 库仅在主动下载备用压缩包时加载。

组件来源、授权与维护说明见 [docs/ui.md](docs/ui.md)。

## 相机日期印记

新增「日期」设置：上传时在本机读取 EXIF，优先使用 DateTimeOriginal（原始拍摄时间），缺失或无效时尝试 CreateDate（数字化时间）。默认将有效年月日以傻瓜相机日期后背风格印在照片右下角：橙色七段数码字、轻微辉光、`'YY MM DD`。没有有效日期则完全跳过；不会使用修改时间、上传时间、文件名或今天的日期来补。

日期印记与片基文字相互独立，可按全部 / 选中照片开关，开关会记住。照片内记录的年月日保持不变，不按浏览器时区换算。预览、缩略图和各档 JPEG / PNG / ZIP 导出使用同一日期数据。原始照片不修改，日期作为像素印入新导出的图片，详情见 [docs/date-stamp.md](docs/date-stamp.md)。

### iPhone 保存照片

导出面板选择画质后，先「准备保存」，再点「保存到相册 / 分享」，在 iOS 系统分享菜单选择「存储图像」保存单张或多张照片。图片处理与分享分为两次点击，保证 Safari 分享调用处于有效用户手势中。网页无法绕过系统菜单直接写入相册；分享操作完成后需在相册确认，取消可重试。

浏览器不支持文件分享或多图分享失败时，可逐张分享，或打开大图长按存储；逐张下载和压缩包下载作为备用，不会自动下载 ZIP。切换画质、调整照片或选择范围会清除已准备的文件，重新生成后再保存；临时图片地址在离开导出面板时释放。

### 多张拼图

底部切换「单张 / 多张拼图」，照片条、主题、片基、文字和日期设置继续沿用本项目。拼图以每张照片的完整胶片边框参与排版，不裁切或旋转照片。点击照片条选中照片，再用预览上方前移 / 后移按钮调整顺序，便于手机操作；「选择」管理和「仅选中」范围可控制哪些照片参与拼图。

「拼图布局」或右上角设置中提供 7 种画布比例（4:5、5:4、2:3、3:2、1:1、9:16、16:9），自动 / 横排 / 竖排 / 网格排列，照片间距、画布留白及背景颜色。默认浅色 4:5 画布；画布颜色独立于网站主题。可输出 1–3 页，照片依序均匀分页；超过 12 张时自动增加页数，确保每张照片恰好出现一次。

拼图预览和导出使用同一排版与渲染函数。导出遵循现有 JPEG / PNG 画质和最终长边尺寸，依次渲染每个完整胶片画面并及时释放中间画布。多页拼图通过现有系统分享保存为多张图片，仍支持逐张下载和备用 ZIP；修改布局会使已准备的文件失效。

功能参考用户提供的 [Sheep Frame](https://sheepframe.com/) 截图（画布比例、排列、分页、间距与留白）。参考站在本环境被网络策略拒绝，未读取或复制其代码；界面与实现独立编写，保持 FILM BLOCK 的移动端布局。

### 预览滑动与单张拼图大小

预览使用 Embla Carousel（embla-carousel-react），单张模式可左右滑动浏览照片，多张拼图可左右滑动翻页。按钮、照片条和滑动状态同步；仅绘制当前与相邻预览，避免为整批照片同时创建大画布。保留纵向页面滚动与系统双指缩放手势。

拼图模式先在照片条中选中照片，再进入设置的「布局」，可独立调整「当前照片大小」（50%–150%）并恢复默认。大小绑定照片 ID，调整顺序或切换分页不会错配；横排、竖排、网格和自动排列按相对大小重新排版，保留完整边框和原图比例，避免重叠或超出画布。预览、JPEG / PNG 和系统分享使用相同的缩放结果。

### 照片顺序

单张和拼图模式的照片条均使用 dnd-kit 排序：手机长按约 220ms 后拖动，鼠标拖动，键盘聚焦缩略图后按空格开始、方向键移动、空格放下、Escape 取消。普通横向滑动仍用于浏览照片条。也可选中照片，用预览上方的前移 / 后移按钮调整。顺序同步到预览、格号、拼图分页与导出；每张照片的边框、日期、大小仍绑定自身 ID。导入全部成功不再弹出提示，仅在有文件无法读取时显示结果。

### 整卷展示（Contact Sheet）

底部新增「整卷展示」，沿用照片条长按排序、点选、前移 / 后移、预览左右滑动、右上设置以及相册保存。点击整卷预览内的画格也可选中对应照片。135 每卷最多 36 张，120 每卷最多 12 张；超过后自动分卷，不遗漏照片。

整卷由连续片基构成，135 使用 35 mm 胶片及标准间距齿孔，120 无齿孔；每格保留原图比例，不旋转、不裁切。片基颜色与纹理统一，格号、文字、日期使用各张照片设置。可调整每行张数、末行空白格、卷名、背景和整卷信息栏。信息栏包含卷号、片基文字与本卷实际拍摄日期范围；无日期不会用当天时间代替。「按拍摄日期排序」稳定排列已知年月日，同日维持已有顺序，无日期排在最后，之后可继续手动排序。

135 可选择每行 3 / 4 / 6 张，120 可选择 2 / 3 / 4 张。预览与 JPEG / PNG 导出使用同一渲染器；预览中的选中描边不进入导出图。多卷可通过系统分享保存为多张图片，画质与最终长边遵循现有导出档位。功能依据用户提供的 Sheep Frame Contact 截图独立实现，不复制第三方代码或品牌素材。
