# 固定 135 / 120 边框

参考 [JamesQiu2005/SpektraLab](https://github.com/JamesQiu2005/SpektraLab) 的 `engine/src/pipeline/overscan.cpp`，查阅版本 [`02d82b5`](https://github.com/JamesQiu2005/SpektraLab/blob/02d82b56cf65f0f8e802a708612edc4e9a4790af/engine/src/pipeline/overscan.cpp)，2026-11-03。

该实现按毫米定义胶片片宽和齿孔。本站使用下列几何事实独立实现 Canvas 渲染，没有移植其代码、品牌边印、随机相机模型、字体、胶片 profiles 或 LUT。

| 参数 | 135 | 120 |
| --- | --- | --- |
| 片宽 | 35 mm | 61 mm |
| 参考画面横跨胶片的尺寸 | 24 mm | 56 mm |
| 双侧片边 | 5.5 mm | 2.5 mm |
| 齿孔纵向长度 | 1.98 mm | 无 |
| 齿孔横向宽度 | 2.80 mm | 无 |
| 孔距（中心距） | 4.75 mm | 无 |
| 齿孔距胶片外缘 | 2.00 mm | 无 |
| 齿孔圆角半径 | 0.50 mm | 无 |

135 的对侧孔使用同一中心网格，标准 36 × 24 mm 照片对应 38 × 35 mm 片段、每侧 8 个孔。不得单独改变孔数、孔形、孔距、孔尺寸、边框宽度或孔底色；120 不能开启齿孔。内框线设置也已移除。

## 与参考项目的区别

SpektraLab 包含多个 120 画幅与相机片门模型，135 片门还采用其测量的约 36.25 × 24.3 mm；它要求照片与所选片门比例匹配。

本站以保留整张照片为优先：以原图短边映射到 24 mm（135）或 56 mm（120），长边保持原比例。并不强制裁为 36 × 24、6 × 6 或其他片门。因此任意长宽比照片的胶片片段长度、135 孔数会自动变化，但孔尺寸、孔距、双侧对齐和片宽比例不变。方图和全景图不会被拉伸或裁切。120 是固定片宽的无孔边框，不宣称还原所有 120 相机画幅。

135 每端添加 1 mm 片间留白，120 每端添加 1.7 mm。孔底色固定为扫描台的浅色。文字位于片基外侧独立空白带，字号以 18–40 档相对缩放，分辨率改变时等比渲染。

颜色、文字、字色、像素字体、字号和纯色 / 细颗粒预设保留。所有几何参数由格式自动决定，不提供高级齿孔控制。
