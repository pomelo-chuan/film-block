# 自动相机日期印记

## 日期来源

上传图片时并行解码图片与读取 EXIF。exifr 7.1.3 仅在上传时动态加载，提取 DateTimeOriginal 与 CreateDate，关闭 GPS、缩略图、MakerNote、用户注释、ICC、IPTC、XMP 等非必要解析。

1. 优先选择合法的 DateTimeOriginal（原始拍摄日期）。
2. 如果缺失或无效，使用合法的 CreateDate（EXIF DateTimeDigitized，数字化日期），界面明确标出来源。
3. 两者都不可用则保存 null，不添加任何日期。ModifyDate、文件 lastModified、文件名、上传时刻和当前日期均不作为替代来源。元数据读取错误不阻止正常图片导入。

保持原始字符串的年月日，不创建 Date 对象、不转 UTC 或浏览器时区。校验真实月天数、闰年、时间与时区字段，拒绝全零和无法解析的日期。没有日期的社交平台转存图、截图等会显示「未读取到照片日期」，而不会编造时间。

## 日期后背样式

- 日期格式固定为 `'YY MM DD`，例如 `'24 02 29`，完整年份可在日期页签查看。
- 照片右下角留出内边距，按原图短边等比缩放，不画到片基或齿孔上。
- 自行绘制七段矢量数码字；橙色核心、暗色衬底与轻微暖色辉光，不依赖额外字体。
- 与边框文字独立。关闭片基文字不会关闭日期印记；日期页签另有独立开关，遵循全部 / 选中应用范围。
- 每张照片持有自己的 CaptureDate，不复用上一张照片的时间；只缓存开关，不缓存照片或拍摄日期。
- 同一个 renderFilm 路径用于预览、缩略图、放大与 JPEG / PNG 导出。ZIP 内每张图使用各自元数据。
- 不改写上传的原文件，也不复制原 EXIF 到导出图；日期印记直接成为导出图的像素。

## 验证

`src/test-fixtures/` 的 JPEG 是程序生成的色块图，包含真实 EXIF IFD，用于原始日期优先、数字化日期回退、非法闰日、仅修改时间等测试，不包含用户照片。

单元测试覆盖合法日期、闰年、时区边界、无有效日期以及日期印记的图内布局。浏览器以 Honolulu 时区验证实际 JPEG 文件，确认不同图片使用不同日期、无日期图像与关闭印记时像素一致，且默认 JPEG、单张 PNG 与四图 ZIP 的日期结果正确；手机、横屏和桌面的日期页签均无横向溢出。
